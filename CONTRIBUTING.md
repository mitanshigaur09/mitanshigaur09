# Contributing

Thanks for stopping by! This is a special **profile** repository for `mitanshigaur09`.
If you spot a typo or a broken link, feel free to open an issue or PR.

## How to contribute
1. Fork the repo.
2. Create a branch: `git checkout -b fix/broken-link`.
3. Commit your changes and open a Pull Request.

All PRs will run link checks via GitHub Actions.
